# Triage 标签

各技能以五个标准的 triage 角色来说话。本文件把这些角色映射到本仓库 issue 追踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库追踪器中的标签 | 含义                                        |
| -------------------------- | -------------------- | ------------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                     |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                       |
| `ready-for-agent`          | `ready-for-agent`    | 已完全明确，可交给 AFK agent                 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                                 |
| `wontfix`                  | `wontfix`            | 不会处理                                     |

当技能提到某个角色（例如「打上 AFK-ready 的 triage 标签」）时，使用本表中对应的标签字符串。

如需改成你实际使用的词汇，直接编辑右侧一列。
